Conectores MCP reales

Cada conector MCP tiene su endpoint, autenticación y scopes configurados. La fábrica prueba la conexión real (handshake JSON-RPC) y expone sus capacidades. Tokens privados se almacenan cifrados en el backend y se muestran mascarados.

Agregar / editar conector MCP

Configura un conector MCP real: endpoint URL, tipo de autenticación, token privado y scopes. La fábrica se conecta de forma autónoma y adapta sus capacidades.

Cada función del pipeline es un agente autónomo. Desde acá se instalan plugins/habilidades y se modifican los prompts de cada parte para que el sistema mejore solo con el tiempo.
